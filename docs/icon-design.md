# iOS app icon

Source identity: upstream `win32/pc98player.ico` (16, 32, 48 and 64 px). The new illustration retains the front-facing beige CRT, dark bezel, four color bars and low stand. It contains no lettering or hardware brand logo.

Created with the built-in ImageGen tool, then resized to an opaque 1024×1024 PNG with macOS sips for asset catalog packaging. iOS applies the outer icon mask. The original upstream icon is unchanged.

Asset: `ios/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.

## Generation prompt

Use case: logo-brand. Create one production iOS app icon, square 1024x1024 opaque PNG artwork, redesigning the attached 64px PC98PLAYER icon at high resolution. Reference image is the identity reference: preserve a straight-on ivory/beige vintage CRT monitor, charcoal thick inner bezel, four vertical test-pattern bars in exactly this order from left to right: coral red, turquoise cyan, periwinkle blue, pale yellow, and a small low beige stand beneath. Preserve simple iconic silhouette and centered front view; no perspective tilt. Render a clean polished retro hardware illustration with restrained bevels, soft studio shading, crisp geometry, extremely legible at small app icon sizes, matching an ivory PC-98 interface. Screen must be large; monitor takes around 80% of canvas width, full monitor and stand fit with generous safe margin. Background: solid warm very dark charcoal covering entire square edge to edge, no transparency. No app icon rounded outer mask, iOS supplies that. No words, no letters, no numbers, no logo, no Apple or NEC branding, no watermark, no separate border. Only one icon filling the image, no mockup, no grid of variations.
