# 全画面メニューの一時停止確認

2026-11-11、0.2.4（ビルド51）と同じアプリ実装で「全画面の長押しメニューから一時停止できない」という報告を調査しました。現時点ではシミュレーターで再現しておらず、アプリ本体の修正は行っていません。

`ios/UITests/FullscreenMenuUITests.mm` は、メソッドの直接呼び出しではなく、実際の長押し・メニュー選択・画面タップを使います。

- 全画面で起動し、長押しメニューの「一時停止」を選ぶ。
- 通常表示で起動し、ダブルタップで全画面へ切り替え、横向きに回転して同じ操作を行う。
- メニューを閉じた後も「再開」が表示され続け、次の画面タップで「一時停止」に戻ることを確認する。

実行結果：iPhone 18 Pro（iOS 27.2）と閉じたDuo（iOS 27.1）で最初のケース、開いたDuoで両ケースが成功しました。実機での再現確認は未実施です。これらはUIの停止・再開状態の確認で、ゲーム進行や音声の実測を代替しません。

UIテストは `IOS_UI_TESTS=ON` でビルドし、対象シミュレーターを指定した `xcodebuild test` に `-only-testing:PC98PLAYERiOSUITests/FullscreenMenuUITests` を渡して実行できます。長押しだけではメニューを表示し、「一時停止」を選ぶと停止するのが現在の仕様です。
