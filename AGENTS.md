# Agent entry point

Read [LOCAL_HANDOFF.md](LOCAL_HANDOFF.md) before starting. It describes how to
clone/build the current main, published versus unreleased changes, validation,
and unresolved reports. Historical handoff notes are not current authorization.

Preserve existing local changes and other agents' updates. Check the current branch
and remote state before integrating changes. Follow the user's current instructions
over historical handoff notes. Never commit signing keys or credentials.
